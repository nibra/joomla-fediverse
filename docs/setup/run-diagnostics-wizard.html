Run the Diagnostics Wizard

Overview

Use the diagnostics tiles to find missing setup pieces quickly and fix them from one place. This saves time during installation and helps you avoid trial-and-error across several Joomla screens.

This step matters because Joomla Fediverse depends on several moving parts at once: a correct public URL, active plugins, working scheduler tasks, and at least one local actor path. The diagnostics module lets you review those dependencies in one screen and jump straight into the corrective action for each failing check. After you complete this procedure, the dashboard should show a clean baseline for the rest of the manual.

Before you begin

  • Complete plugin activation and core options first.
  • Sign in with an account that can manage component configuration.
  • If you already know a check is failing, keep in mind that some actions open another screen or dialog before the dashboard can report success.

Steps

  1. Open Components -> Fediverse -> Dashboard.
  2. Review the current status of the diagnostics tiles.
    • Public Base URL - Confirms the site exposes a usable public federation address.
    • Core Plugins - Confirms the required Fediverse plugins are active.
    • Scheduler Tasks - Confirms the background processing tasks are available and configured.
    • Local Actors - Confirms the site can provision or access local actors for publishing.
    • Permissions - Shows whether the site is still using Joomla-wide permissions or the stricter Fediverse-specific permission mode.
    • Each check now also explains the operational Impact and the practical Next step so you can see why the issue matters before you leave the dashboard.
  3. Read the compatibility expectations block above the checklist before you test with a new remote server.
    • It explains which differences are normal across remote Fediverse software.
    • Use it to distinguish a real local misconfiguration from a remote server presenting standards-based content differently.
  4. Use the action attached to any failing check.
    • Configure URL - Opens the component options so you can correct Public base URL.
    • Activate Plugins - Enables the required Fediverse plugins from the dashboard flow.
    • Configure Tasks - Opens the scheduler task configuration path.
    • Open Actors - Takes you to actor management so you can create or inspect local actors.
    • Open Permissions - Opens component options so you can review the Governance and Permissions tabs together.
  5. After each correction, return to the dashboard and reload the diagnostics state.
  6. Repeat until every required check passes.
  7. Optional: if you want the same overview on Joomla’s Home Dashboard, assign the Fediverse Diagnostics administrator module to that dashboard as well.

Check your result

  • All required diagnostics checks show a passing state.
  • The dashboard no longer points to missing plugins, scheduler configuration, or actor provisioning problems.
  • You can continue into actor creation or publishing without unresolved baseline setup errors.

Troubleshooting

A check stays red after I already fixed it

  • Likely cause: The changed setting was not saved, or the dashboard is still showing older state.
  • Solution: Reopen the affected settings screen, confirm the saved values, then return to the dashboard and refresh it again.

The Local Actors check fails

  • Likely cause: No local actor exists yet, or actor provisioning has not run for a Joomla user.
  • Solution: Create or resave a Joomla user with the Fediverse user plugin enabled, then open the Actors view and confirm the actor exists.

The diagnostics screen looks healthy, but publishing still does not work

  • Likely cause: The baseline setup is complete, but the specific author actor, article author mapping, or worker timing is still wrong for the content you are testing.
  • Solution: Continue with the actor and publishing guides, then verify deliveries and author mapping specifically.
